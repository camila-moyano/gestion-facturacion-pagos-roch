# Control de facturas

Este documento describe los controles propuestos para el sistema de Gestión de Facturación y Pagos de ROCH S.A.

- Verificar que cada factura tenga los datos obligatorios.
- Comprobar que la factura no esté registrada previamente.
- Validar la recepción del bien o servicio.
- Registrar la autorización y el pago.
- Actualizar el estado de cada factura para evitar pagos duplicados.
