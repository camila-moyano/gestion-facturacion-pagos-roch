Sistema de Gestión de Facturación y Pagos – ROCH S.A.

Descripción del proyecto:
Este proyecto propone un sistema para gestionar facturas y pagos de ROCH S.A., mejorar el control administrativo, organizar la información y prevenir registros y pagos duplicados.

Objetivos:
Centralizar la información de facturas y pagos.
Detectar posibles facturas duplicadas.
Facilitar el seguimiento de los pagos.
Reducir errores administrativos.
Herramientas utilizadas
Draw.io para el modelado BPMN.
GitHub para la documentación y el control de versiones.
GitHub Projects para la planificación y seguimiento de tareas.

Indicadores y mecanismos de control:
Se proponen los siguientes criterios para evaluar el funcionamiento del sistema:
Tiempo de respuesta: las consultas deberán responder en un máximo de 3 segundos.
Detección de duplicados: el sistema deberá identificar al menos el 95 % de las facturas duplicadas en las pruebas.
Volumen de prueba: se evaluará el funcionamiento con una base de 10.000 registros.
Control de acceso: se verificará que las áreas involucradas accedan según sus funciones.
Seguimiento del proyecto: se comparará el avance de las tareas con el cronograma previsto de 16 semanas.

Estos valores son criterios propuestos para la evaluación del sistema, no resultados de pruebas realizadas.

Uso de inteligencia artificial:
Se utilizó ChatGPT como herramienta de apoyo para organizar ideas, revisar la redacción, comprender conceptos y estructurar partes de la documentación del proyecto. El contenido fue revisado y adaptado manualmente, verificando que se ajustara a la propuesta y a las consignas del trabajo.

Estado del proyecto:
Proyecto académico en etapa de análisis, diseño y planificación.
