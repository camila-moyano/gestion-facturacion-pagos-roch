Sistema de Gestión de Facturación y Pagos – ROCH S.A.

Descripción del proyecto

Este proyecto propone el desarrollo de un sistema de gestión de facturación y pagos para ROCH S.A., con el objetivo de mejorar el control administrativo de las operaciones, organizar la información y reducir errores en el registro de facturas y pagos.

El sistema permitirá registrar facturas de proveedores, verificar sus datos, detectar posibles duplicaciones, controlar las autorizaciones y actualizar el estado de los pagos realizados.

Objetivos:
Centralizar la información de facturas y pagos.
Evitar el registro y pago duplicado de facturas.
Mejorar el seguimiento de las operaciones.
Facilitar el acceso a la información de las áreas involucradas.
Reducir errores administrativos.

Alcance del proyecto:
La propuesta contempla la interacción de las áreas de Administración y Compras, Finanzas y Tesorería, junto con un sistema encargado de validar y registrar la información.
